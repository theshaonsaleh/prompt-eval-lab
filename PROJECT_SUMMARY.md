## ⚠️ Critical Honesty Notice

**The 1,200 cached responses in `results/mock_cache/` are SIMULATED, not real LLM outputs.**

They were generated by `generate_mock_cache.py` using a random number generator to demonstrate the caching and reproducibility features without requiring an API key.

**The accuracy, consistency, and other metrics derived from these mock responses do NOT represent real model performance.** They are synthetic examples for demonstration only.

To obtain real research findings, users must run the evaluation with their own API key against actual models.

## 🔄 Reproducibility Features

✅ **Response caching** keyed by (model, prompt, seed) tuple
✅ **Offline mode** capability for reproducing previous results
✅ **Pinned dependencies** in requirements.txt

✅ **Self-contained dataset** - no external data dependencies

The caching system genuinely preserves reproducibility - once real API calls are made, results can be reproduced exactly from cache.

## 🚀 How to Use

**Option 1: Explore Framework (No API Key)**
```bash

cd prompt-eval-lab
pip install -r requirements.txt
jupyter notebook evaluation.ipynb
```

**Option 2: Real Research Evaluation**
